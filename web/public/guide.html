Setting up your own Bento

Bento is a recipe, shopping list, pantry and dinner-plan app for a household. It runs on a computer at your place (the "server"), and everyone uses it from their phone. Nothing goes to anyone else's computer.

You'll need
  • A Windows computer that's on while you want to use Bento (Mac or Linux works too, see the end).
  • Android phones for the app. Any phone or computer can also use Bento in its web browser.
  • About 15 minutes.
Steps
  1. Unzip Bento
  2. Start the server
  3. Make your account
  4. Add your household
  5. Get it on the phones
  6. Everyday use, backups and updates

1. Unzip Bento

  1. Right-click the Bento zip file and choose Extract All…, then Extract.
  2. Move the Bento folder somewhere it can stay, like your Documents. Everything Bento saves (recipes, photos, lists) lives inside it, in server\pb_data.
Don't run it from inside the zip. Opening the zip and double-clicking things there doesn't work; extract it first.

2. Start the server

  1. In the Bento folder, double-click Start Bento.bat. A black window opens.
  2. If Windows says "Windows protected your PC": click More info, then Run anyway. (It says this about any program it hasn't seen before.)
  3. If a Windows Security / Firewall box asks about pocketbase: tick Private networks and click Allow. This is what lets phones reach it.
  4. When the window says Server started, it's running. Leave the window open (you can minimise it); closing it stops Bento.

3. Make your account

  1. On the same computer, open a web browser and go to http://localhost:8090
  2. You'll see Set up your Bento. Type your name, a username (like sam) and a password, then click Set up Bento. You're in.

This also makes you the server's admin, for the rare times you need its admin page (see The admin page). Its login is yourusername@bento.local with the same password.

4. Add your household

Just you? Skip this step. With one account, Bento leaves out the sharing parts (like who added each recipe) until you add someone.

  1. In Bento, tap the ⋮ button (top right), then Share Bento (called Household once there are two of you).
  2. Tap + Add someone and give them a name, username and starting password. Bento shows you what to tell them. They can change their password later under ⋮ → Profile.

Anyone in the household can add people, so you can share the job.

Your country is on the same page, under Country. Bento guesses it when you first log in, and it decides which grocery stores the Pantry offers (Australia: Coles and Woolworths; United States: Walmart, Target and Kroger). Somewhere else? Pick Somewhere else, and you can still paste any shop's product link into a pantry item.

5. Get it on the phones

First the phones need a way to reach the computer. There are two ways; try the first, and use the second if it doesn't work or you want Bento away from home too.

Way A: on the same Wi-Fi

  1. Find the computer's address: on the computer, open Settings → Network & internet, click your connection (Wi-Fi or Ethernet), and look for IPv4 address, something like 192.168.1.20.
  2. Your server address is that plus :8090, like 192.168.1.20:8090.
  3. Check it: on a phone connected to the same Wi-Fi, open the browser and go to http://192.168.1.20:8090 (with your numbers). The Bento login should appear.
Doesn't load? Some routers keep Wi-Fi devices apart from cabled computers, or the firewall step was skipped. Run Start Bento.bat again and allow it if Windows asks, or use Way B, which always works.

Way B: with Tailscale (works anywhere)

  1. Install Tailscale (free, from tailscale.com/download) on the computer and on each phone, and sign in with the same account on all of them.
  2. In Tailscale on the computer, find its address: it starts with 100., like 100.64.12.34.
  3. Your server address is that plus :8090, like 100.64.12.34:8090.

Install the app

  1. On the phone's browser, go to http://YOUR-SERVER-ADDRESS/api/cookbook/app/download, like http://192.168.1.20:8090/api/cookbook/app/download. It downloads Bento.apk.
  2. Open the download. If Android asks, allow your browser to install unknown apps. If Play Protect warns about it, tap More details → Install anyway. (It warns about every app that isn't from the Play Store.)
  3. Open Bento, type the server address (like 192.168.1.20:8090), your username and password.

iPhones and computers can use Bento in the browser instead: go to http://YOUR-SERVER-ADDRESS. The app is Android only.

6. Everyday use, backups and updates

Keep the server running

Bento only works while the black window is open on the computer. After the computer restarts, double-click Start Bento.bat again.

To start it automatically: press Windows key + R, type shell:startup and press Enter. Right-click Start Bento.bat, choose Create shortcut (on Windows 11 it's under Show more options), and move the shortcut into the folder that opened.

Back up

Everything is in the server\pb_data folder. Every so often, close the black window, copy that folder somewhere safe (like a USB stick), then start Bento again. To restore, put the copy back in the same place.

Update to a new Bento

  1. Close the black window, and copy server\pb_data somewhere safe first, just in case.
  2. Unzip the new Bento and copy everything from it over your Bento folder, except don't touch server\pb_data (the new zip doesn't have one, so copying over is safe).
  3. Start Bento again. Phones offer the app update the next time Bento is opened.

The admin page

For the rare jobs Bento itself doesn't do, like resetting a forgotten password or removing someone: on the computer, go to http://localhost:8090/_/ and log in with yourusername@bento.local and the password you set up with.

  • Reset a password: click users on the left, click the person, switch on change password, type the new password in both boxes, and click Save changes.
  • Remove someone: click the person, then the ⋯ at the top right of their details, then Delete. Their ratings go with them; recipes they added stay.

The admin login keeps the password you set up with, even if you change your Bento password later in Profile. To change it, click your admin email at the top right of the admin page, then Manage superusers, click yourself, and use change password the same way.

Not on Windows?

Bento's server is a program called PocketBase, which also runs on Mac and Linux (including a Raspberry Pi).

  1. Download PocketBase version 0.40.6 for your system from its release page (the file ending darwin_arm64.zip for newer Macs, linux_arm64.zip for a Raspberry Pi 4 or 5). It has to be this version.
  2. Unzip it and put the pocketbase file in Bento's server folder.
  3. Open Terminal, go to that folder (cd then drag the folder in), and run ./pocketbase serve --http 0.0.0.0:8090. On a Mac, if it's blocked, allow it in System Settings → Privacy & Security and run it again.
  4. Then carry on from step 3.

If something goes wrong

  • The black window closes straight away, or says "address already in use": Bento is probably already running in another window. Look on the taskbar.
  • The login screen doesn't show "Set up your Bento": someone already set it up. Log in with that account, or use the admin page to check the users.
  • A phone can't connect: check the black window is open, then try the address in the phone's browser first (step 5).
